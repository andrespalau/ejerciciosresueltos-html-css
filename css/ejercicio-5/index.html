Diferencias observadas

Cuando se utiliza display: block, el elemento ocupa una línea completa y el siguiente elemento aparece debajo.

Con display: inline, los elementos pueden aparecer en la misma línea y ocupan solamente el espacio necesario para mostrar su contenido.

Con display: inline-block, los elementos pueden permanecer en la misma línea, pero también permiten definir propiedades como el ancho y el alto.

Finalmente, display: none hace que el elemento desaparezca completamente de la página y no ocupe espacio.
